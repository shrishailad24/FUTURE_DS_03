# 📊 Marketing Funnel & Conversion Performance Analysis

## 📌 Project Overview
This project analyzes marketing funnel performance using Python and Tableau. It focuses on understanding customer behavior, campaign performance, and deposit conversions to identify areas for improving marketing effectiveness.

## 🎯 Objectives
- Clean and prepare marketing data
- Analyze customer deposits across different channels
- Study campaign performance by month
- Analyze customer demographics
- Visualize marketing insights using Tableau
- Provide actionable business recommendations

## 🛠️ Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Tableau
- Git & GitHub

## 📂 Dataset
Bank Marketing Dataset

## 📈 Dashboard Includes
- Deposit by Contact
- Deposit by Month
- Deposit by Job
- Age Distribution
- Balance Distribution

## 🔍 Key Insights
- Cellular contact generated the highest customer engagement.
- Marketing campaigns performed better during certain months.
- Deposit subscriptions varied across occupations.
- Most customers were between 30–45 years old.
- The majority of customers had lower account balances.

## 💡 Recommendations
- Focus more on high-performing contact channels.
- Schedule campaigns during high-conversion months.
- Target customer segments with better conversion rates.
- Personalize marketing strategies based on customer profiles.
